# Nag Hammadi & Gnostic finds directory

Starter knowledge for AiBhive Research Lab · Communal Library topic **`nag-hammadi`**.

Goal: harvest every published Nag Hammadi tractate (and major companion Gnostic books) so the community can **search and index the words inside**.

Public-domain / borrowable sources only when publishing. Prefer Archive.org text items and the Gnostic Society Library mirrors. Never invent quotations.

---

## Scout protocol

1. Start from a **paste-ready URL** below (Archive.org search-results or gnosis.org tractate page — not a bare homepage).
2. Fable Scrape: **Crawl on**, max pages 8–15, findings 3–6, mode **text-corpus** for English editions; **image-OCR** for Coptic plate photos.
3. Translate Coptic/Greek glosses → English; keep NHC citations (`II,2`, etc.).
4. Publish to Communal Library with **`topicId: nag-hammadi`**.
5. Ask the user A / B / C which trench to deepen (codex plates vs English edition vs companion texts).

---

## How to answer

- Vague “gnostic / nag hammadi” → offer **3 digs**: (A) Robinson English volume, (B) Gospel of Thomas plates + text, (C) full Codex II harvest.
- Always include at least one paste-ready URL and Fable settings.
- Word-index path: harvest → OCR/text extract → publish `ocrText`/`translation` → communal search substring-indexes title + body.
