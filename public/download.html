Install steps (read this)

  1. Uninstall any old Taylored / AiBhive app first (Settings → Apps → Uninstall). Required if you tried before.
  2. Download the .gz file above.
  3. Open with ZArchiver → Extract once → you get one file: taylored-mobile.apk
  4. Tap that .apk file to install.
Do NOT extract the .apk itself. If you see folders like classes.dex, lib, or AndroidManifest.xml next to the apk, you unzipped the apk by mistake. Delete that folder, re-download, extract only the .gz, then install the single .apk file.
Success check: top-right badge → v1.2.3. Hive beehive background + logo. Build tab → Hive Magic ON.

Still says "App not installed"?

  • Uninstall every copy of the app, reboot phone, try again
  • Do not install app-debug.apk — use taylored-mobile.apk only
  • Enable "Install unknown apps" for ZArchiver or Files
